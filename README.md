# Edge Detection Using Sobel, Prewitt and Canny

## 1. Introduction

This project demonstrates edge detection using Sobel, Prewitt, and Canny techniques. The input image is converted to grayscale and the three methods are applied for comparison.

## 2. Objective

* Detect edges in a grayscale image.
* Implement Sobel, Prewitt, and Canny methods.
* Compare the results.

## 3. Requirements

* Python 3.x
* OpenCV
* NumPy
* Matplotlib
* Google Colab / Jupyter Notebook

## 4. Methodology

* Read and convert the image to grayscale.
* Apply Sobel edge detection.
* Apply Prewitt edge detection.
* Apply Canny edge detection.
* Display and compare the results.

## 5. Output

The program displays:

1. Original Grayscale Image
2. Sobel Edge Detection
3. Prewitt Edge Detection
4. Canny Edge Detection

## 6. Result

The project successfully detects edges using all three techniques and allows their results to be compared.

## 7. Applications

* Image segmentation
* Object detection
* Shape recognition
* Computer vision
* Feature extraction

## 8. Conclusion

Sobel, Prewitt, and Canny are useful edge detection techniques. Canny generally produces thin and well-defined edges.
